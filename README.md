# MessMind

MessMind is a student meal-planning project that will help a hostel mess estimate attendance and reduce food waste.

## Project folders

- `frontend/` — the browser interface
- `backend/` — the API that will connect the interface to the data and prediction logic
- `ml/` — attendance prediction work

## Current status

The frontend is an early prototype. Its attendance number is a sample calculation, not a real prediction. Backend, database, and ML integration are still to come.

## Open the prototype

Open `frontend/index.html` in a web browser. Enter a meal, menu, and student count, then choose **Estimate attendance**.
